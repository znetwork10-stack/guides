מה צריך לפני שמתחילים?

  • אפליקציית Claude למחשב (Windows או Mac), מ-claude.ai/download, עם מנוי שכולל את לשונית Code.
  • למשחקי דפדפן לא צריך שום דבר נוסף. זו הדרך הכי פשוטה להתחיל.
  • ל-Unreal, Unity או Godot צריך שהמנוע עצמו יהיה מותקן במחשב. הסקילים מלמדים את Claude לעבוד איתו, הם לא מחליפים אותו.

Claude כותב שהפקודה claude לא מוכרת

שולחים לו את ההודעה הזו במקום: "תתקין את הסקילים ידנית: תוריד את הפרויקט gamedev-skills/awesome-gamedev-agent-skills מ-GitHub ותעתיק את התיקייה router ואת כל תיקיות הסקילים אל ~/.claude/skills, לפי הקובץ docs/INSTALLATION.md שבפרויקט." אחר כך סוגרים ופותחים את האפליקציה.

אני עובד רק במנוע אחד. חייבים להתקין הכול?

לא. אפשר להתקין רק את הנתב ואת המנוע שלכם, וזה אפילו עדיף אם כבר יש לכם הרבה סקילים. מבקשים מ-Claude להריץ claude plugin install router@awesome-gamedev-agent-skills ואז claude plugin install godot@awesome-gamedev-agent-skills (או unity, unreal, web-engines).

אני משתמש ב-Cursor, Codex או כלי אחר

החבילה עובדת גם שם. בטרמינל (החלון השחור שבו כותבים פקודות) מריצים npx skills add gamedev-skills/awesome-gamedev-agent-skills. צריך Node.js בגרסה 22.20 ומעלה.
