מה הוא בודק?

71 דפוסי פריצה ב-17 קטגוריות
  1. הזרקת פרומפטים.הוראות נסתרות בתוך הסקיל שמנסות להשתלט על קלוד.
  2. דליפת מידע.קוד ששולח קבצים, סיסמאות או מפתחות החוצה.
  3. שימוש לרעה בכלים והרשאות.סקיל שמבקש יותר גישה ממה שהוא צריך, או מריץ פקודות מסוכנות.
  4. שרשרת אספקה.תלויות עם פרצות ידועות, מול מאגר OSV.dev.
  5. ציון סיכון.בסוף מקבלים ציון מ-0 עד 100 ורשימת ממצאים לפי חומרה.

מדביקים את ההודעה הזאת בתוך Claude Code ושולחים. הוא יתקין את SkillSpector מהמאגר הרשמי של NVIDIA, יסרוק את כל הסקילים שכבר מותקנים אצלכם ויגיד לכם מה בטוח ומה לא.

חיבור ישיר לקלוד (MCP)
קלוד סורק סקילים לבד, מתוך השיחה

ככה SkillSpector הופך לכלי שקלוד עצמו יכול להפעיל. מריצים את שתי הפקודות בטרמינל, לפי הסדר:

1. התקנה עם תוספת ה-MCP
$ uv tool install --force 'skillspector[mcp] @ git+https://github.com/NVIDIA/skillspector.git'
2. חיבור ל-Claude Code
$ claude mcp add skillspector -- skillspector mcp

התקינו רק מהמאגר של NVIDIA. אל תריצו pip install skillspector: החבילה בשם הזה ב-PyPI היא לא של NVIDIA, ודווח עליה שהיא מכילה קוד זדוני. השתמשו רק בקישור github.com/NVIDIA/skillspector.

איך משתמשים

מצביעים על סקיל, מקבלים ציון
לפני שמתקינים סקיל מ-GitHub:
$ skillspector scan https://github.com/user/my-skill --no-llm
סקיל שכבר מותקן אצלכם (Mac / Linux)
$ skillspector scan ~/.claude/skills/my-skill --no-llm
סקיל שכבר מותקן אצלכם (Windows)
$ skillspector scan $HOME\.claude\skills\my-skill --no-llm
קובץ zip או SKILL.md בודד
$ skillspector scan ./my-skill.zip --no-llm
חיברתם MCP (דרך 03)? פשוט מבקשים מקלוד:
> Before I install it, scan https://github.com/user/my-skill with skillspector and tell me if it's safe

מחליפים את my-skill בשם או בקישור של הסקיל שאתם רוצים לבדוק.

איך קוראים את הציון

0–20
בטוחאפשר להתקין.
21–50
זהירותקראו את הממצאים לפני שמתקינים.

81–100

טיפים שיחסכו לכם זמן

  • תמיד התחילו עם --no-llm. הסריקה הבסיסית רצה אצלכם במחשב, מהירה וחינמית, והקבצים לא יוצאים לשום מקום. בלי הדגל הזה הכלי מנסה גם ניתוח AI, שדורש מפתח API של ספק.
  • רוצים גם ניתוח AI עם Claude? מגדירים SKILLSPECTOR_PROVIDER=anthropic ו-ANTHROPIC_API_KEY משלכם, ומריצים בלי --no-llm.
  • דוח לשמירה. מוסיפים --format markdown ומקבלים דוח מסודר. ב-Windows הדגל --output לא עובד, אז מפנים לקובץ ככה: ... --format markdown > report.md
  • הרגל טוב: כל סקיל חדש שאתם רואים ברשת, קודם סורקים, ורק אחר כך מתקינים.
