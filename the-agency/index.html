סוכנות AI שלמה, בחינם: The Agency

מאות סוכנים מומחים בקוד פתוח, כמו מעצבי UI/UX, כותבי מודעות, מומחי קמפיינים ועורכי וידאו, שנכנסים ישר ל-Claude Code. לכל אחד אישיות, דרך חשיבה ותהליך עבודה משלו.

170Kכוכבים ב-GitHub
280+סוכנים ב-18 מחלקות
0 ₪קוד פתוח (MIT)

מה יש בפנים?

  • שיווק ומדיה ממומנת: כותבי מודעות, אסטרטגים לרשתות, מומחי קמפיינים, Reddit, TikTok, Instagram.
  • עיצוב: מעצב UI, ארכיטקט UX, מספר סיפורים ויזואלי, מהנדס פרומפטים לתמונות.
  • ועוד 15 מחלקות: הנדסה, מכירות, מוצר, אבטחה, ניהול פרויקטים, פיננסים ועוד.
  • כל סוכן הוא קובץ אחד עם זהות, משימה, כללים, תהליך עבודה ומדדי הצלחה.
חלק 1 · התקנהדרך האפליקציה, או דרך Claude חלק 2 · שימושפשוט מבקשים מסוכן

מה צריך?

  • Claude Code: הלשונית Code באפליקציית Claude למחשב (או בטרמינל, זה עובד אותו דבר).
  • זהו. ההתקנה דרך האפליקציה לא צריכה טרמינל בכלל.

חלק 1 · התקנה

פעם אחת

יש שתי דרכים. בוחרים אחת מהן, ושתיהן מתקינות את אותם הסוכנים.

א

הדרך הקלה: האפליקציהבלי טרמינל, בלחיצה

נכנסים לדף ההורדות של האפליקציה ומורידים את הקובץ שמתאים למחשב שלכם:

https://github.com/msitarzewski/agency-agents-app/releases/latest
  • Windows: הקובץ שנגמר ב-x64-setup.exe
  • Mac: הקובץ שנגמר ב-aarch64.dmg (מעבד M) או x64.dmg (אינטל)

מתקינים, פותחים, בוחרים את המחלקות שאתם רוצים (למשל שיווק, עיצוב ומדיה ממומנת), ובוחרים Claude Code כיעד.

הצלחתם אם האפליקציה מראה שהסוכנים הותקנו ל-Claude Code.

ב

או: מבקשים מ-Claude להתקיןמעתיקים ומדביקים בשיחה ב-Claude Code

תתקין לי את הסוכנים של The Agency מ-GitHub, רק את המחלקות שיווק, עיצוב ומדיה ממומנת. תשכפל את הריפו ותריץ: git clone https://github.com/msitarzewski/agency-agents.git cd agency-agents ./scripts/install.sh --tool claude-code --division marketing,design,paid-media

הצלחתם אם Claude כותב כמה סוכנים הותקנו לתיקייה ~/.claude/agents.

רוצים מחלקות אחרות? מחליפים את רשימת המחלקות בסוף הפקודה, או פשוט מבקשים מ-Claude: "תראה לי את כל המחלקות של The Agency וכמה סוכנים יש בכל אחת".

חלק 2 · שימוש

בכל פרויקט

לא צריך לזכור פקודות. אומרים ל-Claude באיזה סוכן להשתמש ומה לעשות.

1

מבקשים מסוכן ספציפידוגמה, תחליפו במשימה שלכם

תשתמש בסוכן UI Designer ותעצב לי דף נחיתה לעסק שלי: צבעים, טיפוגרפיה וכל הרכיבים.

Claude מעביר את המשימה לסוכן, והוא עובד לפי התהליך והכללים שלו.

2

מרכיבים צוות למשימה גדולהכמה סוכנים ביחד

אני משיק מוצר חדש. תרכיב לי צוות מהסוכנים המותקנים: אחד שיכתוב מודעות, אחד שיבנה אסטרטגיה לרשתות החברתיות ואחד שיתכנן קמפיין. תן לכל אחד לעבוד על החלק שלו ותחבר לי הכול לתוכנית אחת.

כל סוכן עושה את החלק שלו, ו-Claude מאחד את התוצאות.

1
מתקינים רק מה שצריךעדיף כמה מחלקות רלוונטיות מאשר את כל 280 הסוכנים. ככה Claude בוחר מהר ובדיוק.

זה עולה כסף?

לא. הפרויקט בקוד פתוח ברישיון MIT, והאפליקציה חינמית. משלמים רק על המנוי הרגיל של Claude.

איך מסירים סוכן?

מוחקים את הקובץ שלו מהתיקייה ~/.claude/agents, או מסירים אותו מתוך האפליקציה.

עובד גם עם כלים אחרים?

כן. הפרויקט תומך גם ב-Cursor, Codex, Gemini CLI, Copilot ועוד. באפליקציה בוחרים את הכלי כיעד.
