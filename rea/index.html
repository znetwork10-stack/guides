REA

מה הוא עושה?

שלושה שלבים, מהשאלה ועד הפיצ'ר אצלכם
  1. שואלים על פיצ'ר אחד.נותנים לקלוד אפליקציה, תוכנה או אתר, ושאלה: "איך הכפתור הזה עובד?"
  2. הוא מפרק את התוכנה.REA נותן לקלוד לקרוא את הקוד (גם קוד מקומפל) ולראות מה התוכנה עושה כשהיא רצה, מהלחיצה ועד התוצאה.
  3. מסביר ובונה.קלוד מסביר לכם צעד אחרי צעד איך זה בנוי, ויכול לבנות פיצ'ר דומה בשפת הקוד ובפרויקט שלכם.

לפני שמתחילים

  • Claude Code מותקן ומחובר. עוד אין לכם? פקודה אחת למטה.

  • יש שני סוגי פקודות. כל פקודה מסומנת איפה מדביקים אותה:
$ בטרמינל > בתוך Claude Code
התקנת Node.js ב-Windows (PowerShell)
$ winget install --exact --id OpenJS.NodeJS.LTS
התקנת Node.js ב-Mac (עם Homebrew)
$ brew install node
התקנת Claude Code ב-Windows (PowerShell)
$ irm https://claude.ai/install.ps1 | iex
התקנת Claude Code ב-Mac או Linux
$ curl -fsSL https://claude.ai/install.sh | bash

אחרי כל התקנה סוגרים את הטרמינל ופותחים מחדש. ב-Mac בלי Homebrew מורידים את Node.js מ-nodejs.org.

01
הדרך הכי קלה מומלץ
קלוד מתקין את REA בשבילכם

פותחים את Claude Code, מדביקים את ההודעה הזאת ושולחים. הוא יראה לכם את תוכנית ההתקנה, מאשרים, והוא גם יבדוק שהכול עובד.

בתוך Claude Code
> Install REA and connect it to this coding agent using npx rea-agents@latest setup --client claude_code. Show me the setup plan for approval, then verify the installation.
02
התקנה בטרמינל
פקודה אחת, בכל מחשב
בטרמינל
$ npx rea-agents@latest setup --client claude_code

ההתקנה מראה מה היא עומדת לשנות ומחכה לאישור שלכם. היא מוסיפה ל-Claude Code את החיבור (MCP) ואת הסקיל של REA, ושומרת גיבוי של ההגדרות הקיימות. את ההתקנה האופציונלית של Hopper אפשר לדלג בפעם הראשונה. זזים עם החצים, בוחרים עם רווח וממשיכים עם Enter.

ב-Windows, אם PowerShell אומר שהרצת סקריפטים חסומה, כותבים npx.cmd במקום npx.

03
חיבור ידני לפרויקט אחד
למי שרוצה את REA רק בתיקייה מסוימת

מריצים מתוך התיקייה של הפרויקט:

Mac או Linux
$ claude mcp add --scope local rea -- npx -y rea-agents@6.8.0 mcp
Windows
$ claude mcp add --scope local rea -- cmd.exe /d /c npx -y rea-agents@6.8.0 mcp

התקנתם? עוד שני צעדים

1. סגרו את Claude Code עם /exit ופתחו אותו מחדש, כדי שיטען את REA.

2. בדקו שהכול תקין. בתוצאה צריך להופיע "healthy": true

בדיקת תקינות, בטרמינל
$ npx -y rea-agents@latest doctor --client claude_code --json
או פשוט שואלים את קלוד
> Is REA connected? List the REA tools you can use.
use

איך משתמשים

מתחילים כל בקשה ב-"Use REA to…"

אין פקודות מיוחדות. כותבים לקלוד באנגלית או בעברית מה לפרק ומה אתם רוצים לדעת, ומציינים את הנתיב המלא לתוכנה או את הכתובת של האתר. כמה דוגמאות מוכנות:

להבין פיצ'ר באפליקציה שמותקנת אצלכם
> Use REA to understand how search works in the Notes app, show me the evidence, and build a similar feature for my project.
לפרק אתר ולבנות גרסה משלכם
> Use REA to inspect https://example.com. Explain step by step how the signup flow works, from the click to the final request, then build a similar flow in my project's stack.
אפליקציית מחשב (Electron / JavaScript), בטרמינל
$ npx -y rea-agents@latest analyze-javascript-application "/absolute/path/to/app" --json

מחליפים את example.com ואת הנתיב בשלכם. נתיב עם רווחים עוטפים במירכאות.

%

דוגמה מלאה: הכפתור % במחשבון של Windows

למה 200 + 10% נותן 220?
אתם, בתוך Claude CodeUse REA to inspect Windows Calculator's % button. Recover the rules after + and ×, then build a small calculator that uses both.
Claude + REAפתחתי את קובץ ה-DLL של המחשבון וקראתי את ההוראות שמאחורי הכפתור %. יש שני כללים שונים:
אחרי +: לוקחים 10% מהמספר הראשון. 10% × 200 = 20 → 200 + 20 = 220
אחרי ×: הופכים את 10% ל-0.1. 200 × 0.1 = 20
בניתי לכם מחשבון קטן שעובד בדיוק לפי שני הכללים.

עוד דוגמאות אמיתיות

משחק הדינוזאור של Chrome: למה הוא מאיץ?
> Use REA to inspect this dinosaur game. Why does it get faster? Show the speed rule, then build a small version with an adjustable speed.
רוצים להתאמן קודם? הדוגמה המודרכת של האתר
> Download the REA Notes example app from rea.tools, unpack it, and use REA to explain what happens when I click the Export notes button: where notes.csv is written, which fields it contains, and the relevant files and lines.

התקינו רק מהמקורות הרשמיים: github.com/morluto/rea, האתר rea.tools או החבילה rea-agents ב-npm. מסתובבים ברשת עותקים מזויפים של הפרויקט.
ולגבי "להעתיק אפליקציה": מותר ללמוד איך משהו עובד ולבנות פיצ'ר משלכם, אבל העתקה של קוד, עיצוב או מותג של תוכנה בתשלום יכולה להפר זכויות יוצרים ותנאי שימוש. השתמשו בזה כדי ללמוד ולבנות משהו שלכם.

טיפים שיחסכו לכם זמן

  • שאלה אחת, פיצ'ר אחד. "איך עובד הייצוא ל-CSV?" עובד הרבה יותר טוב מ-"תפרק לי את כל האפליקציה".
  • בקשו הוכחות. הוסיפו "show me the evidence" וקלוד יראה לכם את הקבצים והשורות שעליהם הוא מתבסס.
  • תוכנות מקומפלות (C, C++, Rust, Go) צריכות את Ghidra (חינמי), IDA או Hopper מותקנים. אפליקציות JavaScript, Electron ו-.NET עובדות בלי כלום נוסף.
  • עדכון: מריצים שוב npx rea-agents@latest setup ומפעילים מחדש את קלוד. הסרה: npx rea-agents@latest uninstall
  • קלוד לא רואה את REA? צאו מ-Claude Code והיכנסו מחדש, והריצו את בדיקת התקינות שלמעלה.
