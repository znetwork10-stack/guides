מעתיקים כל אתר, אפליקציה ומשחק עם Claude

Craft Anything היא תוכנה חינמית בקוד פתוח, שלומדת איך אתר, אפליקציה או משחק בנויים, ואז נותנת ל-Claude Code לבנות לכם גרסה משלכם. היא גם בודקת את התוצאה מול המקור, שוב ושוב, עד שהיא דומה.

40K+כוכבים ב-GitHub
4שלבים: לומד, בונה, בודק, מוכן
חינםקוד פתוח (MIT / Apache)

איך זה עובד, במשפט אחד: מכניסים כתובת של אתר (או בוחרים אפליקציה או משחק), כותבים מה רוצים, ולוחצים Start. התוכנה לומדת את המקור, Claude בונה, והתוכנה משווה את מה שנבנה למקור ונותנת ציון דמיון, עד שזה מוכן.

מה צריך לפני שמתחילים?

  • מחשב Windows או Mac. המדריך כתוב ל-Windows. הוראות ל-Mac בתחתית העמוד.
  • מנוי Claude בתשלום (Pro או Max). התוכנה בונה בעזרת Claude Code שמחובר לחשבון שלכם, ומשתמשת במכסה של המנוי.
  • 10 דקות להתקנה, פעם אחת.

העתקה והדבקה

כל בקשה נכתבת בתיבה Say what you want, ואפשר לכתוב בעברית. את מה שבסוגריים המרובעים מחליפים בשלכם. כשהתוכנה שואלת אם מותר לה להריץ משהו, מופיע כרטיס: הכי בטוח ללחוץ Allow once.

1

גרסה משלכם לאתר הכי טוב להתחיל מכאן

בוחרים A website, מדביקים את כתובת האתר, משאירים Clean room, מדביקים את הבקשה ולוחצים Start.

תבנה לי אתר משלי בהשראת האתר הזה: אותו מבנה, אותם מרווחים ואותה תחושה, אבל עם הטקסטים, הצבעים והלוגו של העסק שלי. העסק שלי: [מה העסק עושה, איך קוראים לו]. כל התמונות והטקסטים יהיו חדשים ומקוריים.
בצד ימין רואים את השלבים מתמלאים: Study, Build, Check, Ready, וציון Likeness שעולה.
2

משחק מאפס

בוחרים Nothing — start fresh, מדביקים ולוחצים Start.

תבנה לי משחק נחש פשוט ב-Rust, עם ניקוד, מהירות שעולה עם הזמן ומסך "נגמר המשחק" עם כפתור "שחק שוב".
בסוף מופיע כפתור לפתוח את המשחק ולשחק בו.

משנים מה שלא אהבתם

כשהפרויקט מוכן, כותבים בתיבה שבתחתית המסך (Ask for a change) ושולחים.

תעשה את הכותרת הראשית גדולה יותר בצבע [צבע], ותוסיף בסוף העמוד טופס יצירת קשר עם שם, טלפון והודעה.
התוכנה בונה שוב, בודקת, ומעדכנת את הציון.

נפתחת תיקייה עם הקבצים של האתר או המשחק שנבנה.

התוכנה לא מוצאת חשבון מחובר. חוזרים על צעד 2 (claude auth login), סוגרים את Craft Anything לגמרי ופותחים שוב.
