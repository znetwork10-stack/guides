Lemo-Opuscar סרטונים ב-66 סגנונות

SkillSpector אנטי-וירוס לסקילים

תתקין לי את SkillSpector של NVIDIA עם הפקודה הזו. אם חסר לך uv, תתקין אותו קודם: uv tool install git+https://github.com/NVIDIA/skillspector.git
קלוד מריץ skillspector --help ורואים את רשימת הפקודות.

העתקה והדבקה
1

סרטון בסגנון שאתם בוחרים

את כל 66 הסגנונות אפשר לראות בגלריה שלהם: lemomo-ai.github.io/lemo-opuscar

עם Lemo-Opuscar, תציע לי 3 סגנונות שמתאימים לסרטון של 30 שניות על [הנושא שלכם], ואחרי שאבחר תכין אותו.
קלוד מציע סגנונות, ואחרי הבחירה שומר קובץ וידאו בתיקייה של השיחה.
2

Ponytail עובד לבד

לא צריך לבקש כלום: הוא פעיל בכל שיחה, ומעל תיבת הכתיבה מופיע פס עם העלות והטוקנים של המשימה. רוצים לשנות את העוצמה?

/ponytail lite

יש שלוש רמות: lite, full (ברירת המחדל) ו-ultra. /ponytail off מכבה אותו.

הפס מעל תיבת הכתיבה מראה את הרמה החדשה.
3

מחקר מהאינטרנט

תשתמש ב-Agent Reach ותביא לי מה אומרים ביוטיוב ובאתרים על [הנושא שלכם] בחודש האחרון. תסכם בעברית ותוסיף קישורים.
מקבלים סיכום עם קישורים למקורות.
4

בודקים סקיל לפני שמתקינים

לפני שאני מתקין, תסרוק עם skillspector (עם ‎--no-llm) את הסקיל הזה ותגיד לי בעברית אם הוא בטוח: [קישור GitHub לסקיל]
מקבלים ציון סיכון ורשימת ממצאים. ציון גבוה = לא מתקינים.

שווה לדעת

1
אינסטגרם, לינקדאין ורדיט דורשים התחברותב-Agent Reach, יוטיוב, GitHub ואתרים רגילים עובדים מיד. רשתות חברתיות הן ערוצים נוספים שמוסיפים ("תוסיף לי את ערוץ רדיט"), והם משתמשים בהתחברות שכבר יש לכם בדפדפן. קלוד אף פעם לא צריך את הסיסמה שלכם.
2
מספרי החיסכון של Ponytail הם של המפתחלפי המבחנים שלו: 45% פחות טוקנים ו-53% פחות קוד. אצלכם המספר יכול להיות אחר, תלוי בסוג העבודה.
3
סורקים לפני כל התקנהגם כלים פופולריים. לפי המחקר של NVIDIA, ב-26% מהסקילים שנבדקו נמצאו חולשות.
קלוד אומר שהפקודה claude לא נמצאה

כותבים לו: "תתקין את הפלאגין דרך מסך הפלאגינים של האפליקציה, או תמצא את קובץ claude שהאפליקציה משתמשת בו ותריץ איתו את אותן פקודות". אפשר גם לכתוב בשיחה /plugin ולהוסיף משם את ה-marketplace.

Lemo-Opuscar לא מצליח ליצור סרטון

הוא צריך במחשב Node 20+, ffmpeg 7+ ו-Python. כותבים לקלוד: "תבדוק שיש לי את מה ש-Lemo-Opuscar צריך ותתקין מה שחסר".
