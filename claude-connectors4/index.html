4 מחברים שהופכים את Claude לחזק פי כמה

מחקר עמוק בזמן אמת, קריאה של כל אתר, דפדפן משלו, וחיבור לכל האפליקציות שלכם. מתקינים פעם אחת, והוא משתמש בהם לבד.

4מחברים, כל אחד ביכולת אחרת
~10דקות התקנה, בלי לכתוב קוד
1000+אפליקציות דרך Composio

איך זה עובד, במשפט אחד: "מחבר" (Connector, נקרא גם MCP) הוא כלי שמוסיפים ל-Claude. אחרי שמחברים, פשוט מבקשים בעברית, ו-Claude בוחר לבד באיזה כלי להשתמש.

חלק 1 · התקנה4 צעדים, מחבר בכל צעד חלק 2 · שימושפרומפטים מוכנים להעתקה

מה צריך לפני שמתחילים?

  • אפליקציית Claude למחשב (Windows או Mac), מ-claude.ai/download. שלושת המחברים הראשונים עובדים גם באתר, הרביעי (Playwright) רק באפליקציה.
  • חשבון Claude בתשלום (Pro ומעלה) מומלץ. בחשבון החינמי מספר המחברים מוגבל.
  • יתרה קטנה ב-API של Perplexity, רק לצעד 1. משלמים שם לפי שימוש.

חלק 1 · התקנה

4 צעדים

בכל הצעדים נכנסים לאותו מקום: באפליקציית Claude לוחצים על השם שלכם למטה ← Settings ← Connectors. (בגרסאות חדשות זה נקרא Customize ← Connectors.)

1

Perplexity מנוע מחקר בזמן אמת

ב-Connectors לוחצים Add custom connector. בשם כותבים Perplexity, ובכתובת מדביקים:

https://api.perplexity.ai/mcp

לוחצים Add ואז Connect. נפתח דפדפן: נכנסים לחשבון Perplexity, בוחרים את ארגון ה-API לחיוב ומאשרים.

אין עדיין יתרה? נכנסים ל-console.perplexity.ai, מוסיפים אמצעי תשלום וטוענים סכום קטן. כל חיפוש עולה סנטים בודדים.

ליד Perplexity מופיע Connected.
2

Firecrawl קורא כל אתר לעומק

ב-Connectors לוחצים Browse connectors (הספרייה של Claude), מחפשים Firecrawl ולוחצים Connect. נפתח דפדפן: נרשמים ל-Firecrawl (יש מסלול חינמי) ומאשרים.

לא מוצאים אותו בספרייה? מוסיפים אותו כמו בצעד 1, עם השם firecrawl והכתובת הזו:

https://mcp.firecrawl.dev/v2/mcp-oauth
ליד Firecrawl מופיע Connected.
3

Composio חיבור אחד לכל האפליקציות

שוב Add custom connector. בשם כותבים Composio, ובכתובת מדביקים:

https://connect.composio.dev/mcp

לוחצים Add ואז Connect, ונרשמים ל-Composio בדפדפן.

ליד Composio מופיע Connected. את האפליקציות עצמן (Gmail, Notion, Slack ועוד) מחברים בהמשך, כש-Claude מבקש.
4

Playwright דפדפן משלו, רק באפליקציה למחשב

א. מתקינים Node.js (הגרסה שמסומנת LTS) מ-nodejs.org. התקנה רגילה, Next עד הסוף.

ב. באפליקציית Claude: Settings ← Developer ← Edit Config. נפתח קובץ טקסט. אם הוא ריק או שכתוב בו רק {}, מחליפים את כל התוכן בזה ושומרים:

{ "mcpServers": { "playwright": { "command": "npx", "args": ["@playwright/mcp@latest"] } } }

כבר יש שם תוכן? אל תמחקו אותו. ראו "יש לי כבר משהו בקובץ" למטה.

ג. סוגרים את Claude לגמרי (ב-Windows: קליק ימני על האייקון ליד השעון ← Quit) ופותחים מחדש.

ב-Settings ← Developer מופיע playwright עם running.

Claude מחובר לארבעתם

מעכשיו פשוט מבקשים, והוא בוחר לבד את הכלי הנכון.

חלק 2 · שימוש

העתקה והדבקה

פותחים צ'אט חדש. בפעם הראשונה ש-Claude משתמש בכלי הוא מבקש אישור, ולוחצים Allow.

1

מחקר עמוק Perplexity

תשתמש ב-Perplexity ותעשה לי מחקר עמוק: מה השתנה החודש בשוק [התחום שלי] בישראל? תביא נתונים עדכניים עם מקורות.
מקבלים סיכום עם קישורים למקורות, לא ניחושים.
2

לפרק אתר של מתחרה Firecrawl

תשתמש ב-Firecrawl ותקרא לעומק את האתר [כתובת]. תגיד לי: מה הם מוכרים, באיזה כלים ותוכנות הם משתמשים, מי המתחרים שלהם, ואיזה 3 פיצ'רים שווה לי לקחת לאתר שלי.
מקבלים פירוק מסודר של האתר והמלצות.
3

לעבוד בדפדפן בשבילכם Playwright, באפליקציה למחשב

תשתמש ב-Playwright, תפתח את האתר [כתובת], תבדוק שכל הכפתורים והקישורים בעמוד הבית עובדים, ותגיד לי מה שבור.
נפתח חלון דפדפן ו-Claude עובד בו לבד מול העיניים שלכם.
4

לחבר את כל האפליקציות Composio

תשתמש ב-Composio, תחבר את ה-Gmail שלי, תמצא את 5 המיילים הכי חשובים מהשבוע ותסכם לי אותם בנקודות.
בפעם הראשונה נפתח קישור לחבר את Gmail. מאשרים פעם אחת, וזהו.

יש לי כבר משהו בקובץ Edit Config

אם יש כבר "mcpServers", מוסיפים בתוכו רק את החלק של playwright, עם פסיק אחרי השרת הקודם. הכי פשוט: פותחים צ'אט בלשונית Code באפליקציה ומדביקים:

תוסיף לקובץ claude_desktop_config.json שלי את שרת ה-MCP של Playwright (npx @playwright/mcp@latest) בלי למחוק שום דבר שכבר יש בו.
playwright מופיע עם שגיאה

כמעט תמיד זה Node.js שלא הותקן, או ש-Claude לא נסגר לגמרי. התקינו מ-nodejs.org, הפעילו מחדש את המחשב ופתחו את Claude שוב.

אין לי כפתור Add custom connector

בחשבונות Team ו-Enterprise רק מנהל הארגון מוסיף מחברים, דרך Organization settings ← Connectors.
